# CSE160 – Assignment 4: Lighting

This project extends my previous WebGL virtual world by implementing a complete Phong lighting system with interactive controls, multiple light sources, and normal visualization. The focus of this assignment is accurate lighting calculations, proper normal handling, and shader-based rendering using GLSL. The scene demonstrates dynamic lighting effects on multiple 3D objects, including cubes (self-place), spheres, and a loaded Bunny OBJ model.
