# CSE160 – Assignment 3: Virtual World

This project renders an interactive 3D virtual world using WebGL, featuring textured terrain, a skybox, and a block-based environment. The world includes a custom-built castle structure, multiple textured blocks, and an explorable environment implemented with transformation matrices and perspective projection. The minigame I implemented was to rescue the cats from this castle which require removing blocks to reach their position. Some extra features include a full hotbar to change between textured blocks, a button to wipe the initial castle that builds on spawn(or just to clear anything) so you can free build yourself, and player collision to prevent ghosting. You can also fly for better movement. Build to your desires!
