# ASG1 – Interactive WebGL Drawing Tool

This project is an interactive WebGL drawing application that lets you draw squares, triangles, and circles on a 400×400 canvas. You can control brush size, shape type, and color using RGB sliders (0–255) with a live color preview, as well as preset color buttons and an eraser. The page supports undo, clear, reset, and a changelog panel documenting extra features. The application also includes a button to render a predefined reference drawing. Open `asg1.html` in a WebGL-compatible browser to draw using your mouse.
