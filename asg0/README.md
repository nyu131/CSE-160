# ASG0 – Vector Visualization

This project lets you draw and visualize 2D vectors on a 400×400 black canvas using `cuon-matrix-cse160.js`. You can set the coordinates of two vectors (`v1` in red, `v2` in blue), perform basic vector operations (add, subtract, multiply, divide), compute magnitude, normalize vectors, calculate the angle between them, and the area of the triangle they form. Open `asg0.html` in a browser and use the input boxes and buttons to interact with the vectors. Console output shows numeric results for magnitude, angle, and area.
